# 🏍️ Moto Garage

Moto Garage is a simple web app that helps you keep track of your motorcycles and their maintenance history.

You can add your bikes, log service work, and see how much you’ve spent over time.

---

## 🌐 Live App
https://your-app-name.onrender.com

---

## ✨ What it does
- Save your motorcycles in one place
- Record maintenance and repairs
- Track parts, labor, and total costs
- Keep history organized per bike
- Secure login (your data is private)

---

## 🛠️ Built With
- Django (web framework)
- PostgreSQL (database)
- Render (hosting)
